# Tiziana Amicarella — Personal Portfolio & Website

Personal portfolio and professional showcase for **Tiziana Amicarella** (Senior Developer Engineer, Software Developer, Backend Developer, Full Stack Developer, AWS, Azure, Node.js, React, Java, Spring Boot, PostgreSQL, Microservices). Built with a focus on performance, accessibility, SEO, and multi-language support.

---

### 🚀 Key Features

- **⚡ Lightweight & Fast:** Pure HTML5, Vanilla CSS3, and JavaScript (No heavy frameworks or bulky JS dependencies).
- **🌍 Internationalization (i18n):** Instant client-side English/Spanish toggle with persistent language preference via `localStorage`.
- **📱 Fully Responsive:** Adaptive layout with a mobile hamburger navigation menu.
- **🛡️ Secure Contact Form:** Serverless contact routing with Honeypot anti-spam protection and dynamic Math CAPTCHA.
- **🔍 SEO & Entity Optimization:** Structured JSON-LD (`Person` Schema), Open Graph tags, canonical links, and XML image sitemap.
- **☁️ Cloud Assets Integration:** Downloadable CVs served directly via AWS S3 CDN infrastructure.

---

### 🛠️ Tech Stack & Architecture

- **Frontend:** HTML5, CSS3 (Custom CSS Variables & Flexbox/Grid), JavaScript (ES6+)
- **Icons & Fonts:** FontAwesome 6, Flag-Icons, Google Fonts (Inter)
- **Cloud Infrastructure:** Hosted on Cloudflare Pages / AWS S3 Assets
- **Analytics & SEO:** Schema.org Person JSON-LD, Sitemap XML with Google Image extensions
